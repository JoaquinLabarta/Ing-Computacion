****** Linux net NAT commands ******

*** Agregar reglas de NAT:

 iptables -t nat -A POSTROUTING -s 192.168.1.0/24 -o eth0 -j MASQUERADE

# 192.168.1.0/24 es el bloque IPv4 detrás del NAT

*** Quitar:

 iptables -t nat -D POSTROUTING -s 192.168.1.0/24 -o eth0 -j MASQUERADE

*** Ver estado:

 iptables -t nat -L -n -v
 netstat-nat (no esta más)

*** Otras formas:

iptables -t nat -A POSTROUTING -s 192.168.1.0/24 -o eth0 -j SNAT --to 100.0.7.33
iptables -t nat -D POSTROUTING -s 192.168.1.0/24 -o eth0 -j SNAT --to 100.0.7.33

# 100.0.7.33 (Es la IP de la interfaz eth0 del router donde se corre el comando)
# 192.168.1.0/24 es el bloque IPv4 detrás del NAT

*** Ver reglas y tabla de nat

iptables -L -n -v -t nat
conntrack -L
